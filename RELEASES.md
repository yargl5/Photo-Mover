## Что скачивать

- **PhotoMover-vX.Y.Z.exe** — готовая программа Windows x64, Python устанавливать не нужно.
- **SHA256SUMS.txt** — контрольная сумма конкретного EXE.
- **Source code** — исходники из Git-тега, не установочный файл.

Пример проверки загруженного файла в PowerShell:

```powershell
Get-FileHash .\PhotoMover-v1.4.0.exe -Algorithm SHA256
```

Сравните результат со строкой из `SHA256SUMS.txt` того же релиза.

## Исторические сборки

Номера ранних сборок назначены при оформлении истории релизов. Неудачные
промежуточные технические пересборки отдельно не публиковались.
Для v0.0.1-preview, v0.0.2, v0.1.0 и v1.0.0-preview сохранились EXE,
но точного снимка исходников в Git нет. Их теги привязаны к базовому коммиту;
автоматические архивы **Source code** не являются точными исходниками этих EXE.
Это отдельно указано в соответствующих релизах.

Версии v0.x проверяли размер файла, а не SHA-256; для переноса с удалением
оригинала рекомендуется актуальная MTP 1.4. Совпадения в 1.4 проверяются по имени
и относительному пути в выбранной папке, затем по содержимому; поиска по всей
памяти телефона нет.
