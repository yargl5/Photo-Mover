# Photo Mover

Перенос файлов из папки на телефон или другой накопитель с автоматическим освобождением места на ПК.

![Windows](https://img.shields.io/badge/platform-Windows-0078D4?logo=windows&logoColor=white)
![Python](https://img.shields.io/badge/python-3.12-3776AB?logo=python&logoColor=white)

## Что умеет

- выбирает папку-источник и папку назначения;
- сохраняет структуру подпапок;
- показывает процент, скорость и примерное оставшееся время;
- видит телефоны через USB / MTP, даже если у них нет буквы диска;
- проверяет содержимое копии по SHA-256, включая обратное чтение с телефона;
- удаляет исходник только после успешной проверки;
- останавливает перенос без потери уже проверенных файлов;
- работает в оконном и полноэкранном режимах;
- адаптируется к размеру окна и DPI экрана.

## Быстрый запуск

1. Скачайте [PhotoMover-MTP.exe](PhotoMover-MTP.exe) из этого репозитория.
2. Подключите и разблокируйте телефон. В USB-настройках выберите **Передача файлов / MTP**.
3. Запустите программу.
4. Выберите папку с файлами на ПК.
5. Нажмите **Телефон USB / MTP…**. Двойным щелчком откройте телефон, внутреннюю память и нужную папку. Нажмите **Выбрать эту папку**.
6. Нажмите **Начать перенос**.

Исходный файл удаляется только после совпадения SHA-256 оригинала и копии. Копия на телефоне читается обратно через Windows Portable Devices без создания второй временной копии на диске ПК.

Если в папке назначения уже есть файл с тем же именем и относительным путём, программа проверяет размер и SHA-256. При полном совпадении удаляется только исходник на ПК, повторной записи на телефон нет. Если содержимое отличается, оба файла сохраняются, конфликт виден в журнале. Такое поведение работает и для MTP, и для обычных папок.

Проверяются копии по соответствующему пути в выбранной папке назначения. Фото с другим именем или в другой папке телефона автоматически не разыскиваются: полное сканирование памяти потребовало бы чтения всех фотографий.

При ошибке USB, несовпадении хеша, изменении оригинала во время проверки или конфликте имён оригинал сохраняется. После прерывания на телефоне может остаться неполная копия; проверьте её перед повторным запуском. Если телефон занят другим переносом, программа сообщает об этом и сохраняет исходники.

Кнопка **Выбрать…** рядом с назначением остаётся для обычных папок и накопителей с буквой диска. Поддержка телефона требует доступного для записи MTP/WPD-хранилища; один лишь показ устройства в проводнике не гарантирует такую возможность.

## Управление окном

- `F11` — включить или выключить полный экран;
- `Esc` — выйти из полного экрана;
- кнопки управления остаются доступны при уменьшении окна.

## Запуск из исходника

```powershell
python PhotoMover.py
```

## Сборка EXE

```powershell
python -m pip install pyinstaller
.\build.ps1
```

Сборка включает MTP-модуль и MediaDevices 1.10.2. Требуется Windows x64 с .NET Framework 4.5 или новее (входит в Windows 10/11). Для запуска из исходника нужны файлы `mtp_backend.py` и каталог `vendor/MediaDevices` рядом с `PhotoMover.py`.

## Проверки

```powershell
python -m unittest discover -s tests -v
```

Десять автоматических тестов проверяют локальный перенос, подпапки, пустые файлы, совпадающие копии, конфликты имён, отмену, ошибку USB, несовпадение хеша и изменение исходника. Реальные USB-тесты выполнены на Xiaomi 17 Pro: три тестовых файла прошли обратную проверку SHA-256, исходники удалены с ПК. Отдельно проверены удаление оригинала при существующей идентичной копии без загрузки и сохранение исходника при конфликте одинакового размера.

Диагностика собранного EXE без переноса файлов:

```powershell
.\PhotoMover-MTP.exe --diagnose-mtp report.json
```

Лицензии сторонних компонентов: [THIRD_PARTY.md](THIRD_PARTY.md).

## Скорость MTP

Для всей партии используется одно соединение с телефоном. Повторный запуск
MTP-модуля для каждого файла исключён. SHA-256 и обратное чтение сохранены:
показываемая в **МБ/с** скорость учитывает перенос и проверку, а не только запись.
В журнале указано время записи и проверки каждого файла.
Повторные проверки уже доступных папок исключены в пределах одного соединения;
проверки наличия самих файлов сохранены. Совпадающие копии не загружаются заново.

В одном тесте на Xiaomi 17 Pro файлы по 256 КБ после первого подключения
передавались примерно с 3 МБ/с вместо 1 МБ/с, файл 4 МБ — с 9,3 МБ/с
вместо 6,9 МБ/с. Это измерение конкретного подключения, а не гарантия скорости.
